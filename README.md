### CyberCore Worker — AI Station Pro v1.6 (Stable Release)

CyberCore Worker — это локальная многофункциональная рабочая станция интеллектуальной автоматизации, предназначенная для автономной разработки, анализа медиаданных, администрирования СУБД и выполнения сценариев автоматизации операционной системы. Станция функционирует полностью в офлайн-режиме, не отправляя данные во внешние облачные сервисы. 

### 🚀 Ключевые архитектурные подсистемы

1. Автономный ИИ-Агент (Auto AI)
Класс агентов Auto-GPT с поддержкой кроссплатформенной трансляции консольных команд, автоматическим созданием структуры папок, патчингом исходного кода и многоконтурным RAG-поиском.
2. Локальная диффузия (Генерация изображений)
Двухконтурный графический модуль на базе весов Stable Diffusion (.safetensors / .ckpt). Поддерживает автоматический перевод русскоязычных промптов через Ollama, ручное управление параметрами Steps, CFG, Seed и негативными запросами. Инференс оптимизирован для работы на CPU и ускорителях Intel Arc Xe2.
3. Интеллектуальное зрение и OCR (Cyber Vision)
Мультимодальный контур анализа изображений и покадровой раскадровки видеофайлов через OpenCV. Включает полностью автономный движок EasyOCR для автоматического извлечения текста из документов и схем.
4. Синхронная песочница и AI Self-Healing
Изолированная среда выполнения Python-скриптов. При обнаружении критического исключения или синтаксической ошибки ИИ перехватывает Traceback, локализует дефект, генерирует исправленное решение и автоматически обновляет код в редакторе.
5. Многоконтурная подкачка контекста (Context Swap)
Система защиты от переполнения оперативной памяти. При заполнении контекстного окна Ollama на 85%, детальная история автоматически архивируется в дисковый swap-лог, а в ОЗУ закрепляется лаконичная семантическая выжимка текущего статуса проекта.
6. Локальный синтез и распознавание речи
Асинхронная запись звука с микрофона и транскрибация через Whisper tiny. Потоковый синтез речи (TTS) на базе Kokoro-82M OpenVINO/SAPI с автоматической фильтрацией технического кода и разметки.

При активации режима автоматизации ИИ-Агент получает доступ к следующим инструментам через строго структурированный JSON-формат: 

### Управление файловой системой и кодом

* write_file — Создание или перезапись файлов проекта с автоматическим созданием резервных копий .bak при конфликтах доступа.
* patch_file — Точечная замена целевых строк кода в файлах объемом более 40 строк для экономии контекста.
* move_file / delete_file_or_folder — Переименование, перемещение и полная очистка объектов на жестком диске.
* read_file / read_file_lines — Чтение документов целиком или в рамках заданного диапазона строк с индексацией.
* list_dir / check_file_exists / file_search_glob — Инспекция директорий и сквозной поиск файлов по маске во всех подпапках воркспейса.

### Системная интеграция и терминал

* run_terminal_command — Запуск команд в изолированном venv. Графические GUI и интерактивные приложения (Pygame, Tkinter) запускаются асинхронно в параллельном окне, исключая зависание основной командной панели.
* install_package — Автоматическая установка недостающих модулей через pip.
* get_process_list / kill_process_by_pid — Мониторинг запущенных в ОС процессов и принудительное завершение зависшего софта по его PID.
* read_env_variable / clipboard_get_text / sys_get_disk_space — Нативный сбор системных метрик без вызова консоли.

### Сеть и Базы данных

* web_search — Отказоустойчивый контур поиска информации в интернете (DuckDuckGo Lite -> DDG API -> Yahoo) без JS-зависимостей.
* fetch_web_page_text — Извлечение чистого текстового слоя из веб-документации с очисткой от тегов.
* network_download_file — Прямое скачивание программного обеспечения, датасетов и лицензий по URL-ссылке.
* db_execute_query — Универсальный хаб выполнения SQL-запросов и администрирования локальных и сетевых баз данных (SQLite, PostgreSQL, MySQL).

### Векторный RAG и Медиа-контур

* rag_index_text / rag_search — Сохранение, векторизация локальных документов в СУБД ChromaDB и интеллектуальный семантический поиск по ним.
* generate_image_diffusion — Двухконтурная генерация текстур, концепт-артов и графики по детальным английским промптам.
* generate_video_ltx — Локальный синтез видеороликов через диффузионную модель LTX-2.3.
* excel_csv_read / excel_csv_write — Чтение и экспорт структурированных таблиц данных через pandas и openpyxl.
* extract_document_text — Прямой нативный парсинг текстового слоя из PDF и DOCX документов.
* get_image_metadata — Извлечение EXIF-метаданных, разрешения и цветовых каналов для ИИ-анализа.
* vision_analyze_file — Принудительная передача графического файла в зрячие слои модели для визуальной экспертизы дефектов рендеринга и артефактов.

### ⚙️ Настройка параметров генерации (Панель управления)

* Temp (Температура, 0.0 - 1.5): Регулирует креативность. Для написания строгого программного кода выставляйте 0.1 - 0.2. Для творческих задач и текстов — 0.8 - 1.2.
* Top_P / Top_K: Ограничение выборки слов. Рекомендуемые стабильные значения: Top_P = 0.9, Top_K = 40.
* Mirostat (0, 1, 2): Алгоритм контроля качества текста в режиме реального времени для подавления галлюцинаций модели.
* Контекст чата (num_ctx): Лимит памяти истории (до 262 144 токенов). При превышении лимита на 85% срабатывает Swap-менеджер.
* Лимит вывода (num_predict): Максимальный объем токенов в одном ответе (до 32 768 токенов). Если генерация прервалась, используйте кнопку "Далее".
