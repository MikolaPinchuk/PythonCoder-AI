# PythonCoder AI — Workstation Pro 🚀

Полностью автономная, локальная инженерная рабочая станция ИИ, спроектированная для написания кода, глубокого анализа документов (RAG) и безопасного тестирования скриптов прямо в интерфейсе. 100% конфиденциальность данных: все вычисления и базы данных работают строго на вашем локальном ПК без отправки запросов на внешние сервера.

## 👥 Авторы проекта
Программа разработана и оптимизирована в совместном инженерном тандеме:
* **ИИ GOOGLE** (Архитектура, асинхронная логика, парсинг синтаксиса и QSS-интерфейс)
* **MIKOLA PINCHUK** (Главный инженер, концепт-дизайнер, верификация кода и интеграция функций)

---

## 🛠️ Главные особенности и функционал

1. **💻 Локальный запуск (Ollama & Whisper)**: Полная независимость от облачных API. Поддержка любых GGUF-моделей.
2. **🔄 Встроенная песочница**: Безопасное выполнение сгенерированного кода Python в один клик с выводом результатов в чат.
3. **🌐 Локальный веб-поиск (Web RAG)**: Перед отправкой запроса программа собирает свежие факты через DuckDuckGo, Google или Yandex и обогащает контекст ИИ.
4. **📎 Файловый RAG (Скрепка документов)**: Парсинг и анализ локальных файлов `.txt`, `.py`, `.log`, `.pdf`, `.docx`.
5. **🔌 Система ИИ-Агента**: Возможность автоматического вызова встроенных утилит Windows (`calc`, `notepad`, `explorer`, `cmd`, `taskmgr`) через ответы ИИ.
6. **🗄️ Энергонезависимость**: Автоматическое сохранение всех веток чатов, вкладок и положений ползунков в базу данных SQLite (`ai_combain.db`).
7. **🎨 Интерфейс**: Переключаемый Cyberpunk-дизайн со скрываемой боковой панелью истории для максимального фокуса на коде.

## 📦 Быстрый старт и установка

Перед запуском программы выполните одну команду в терминале Windows для установки всех необходимых библиотек:

```bash
pip install ollama psutil sounddevice numpy faster-whisper pygments tiktoken pypdf python-docx PyQt6
```

### Запуск приложения:
1. Убедитесь, что на ПК запущен локальный сервер **Ollama**.
2. Запустите скрипт:
```bash
python AI_CLI_v85.py
```
Ты — ИИ-Агент. Если пользователь просит открыть программу, ты ОБЯЗАН встроить в свой ответ специальный тег:
- Для калькулятора: [RUN_CMD: calc]
- Для блокнота: [RUN_CMD: notepad]
- Для диспетчера задач: [RUN_CMD: taskmgr]
Пиши тег в точности так, как указано.
